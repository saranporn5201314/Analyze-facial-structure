# โฟลเดอร์นี้สำหรับไฟล์โมเดล

หลังจากรัน `faceshape-local/train_face_shape.py` เสร็จ (ดู `faceshape-local/README_SETUP.md`) จะได้ไฟล์ในโฟลเดอร์ `faceshape-local/output/tfjs_model/` ดังนี้:

- `model.json`
- `group1-shard1of*.bin` (ไฟล์ weight อาจมีหลายไฟล์)
- `class_indices.json`

ให้เอาไฟล์ทั้งหมดนี้มาวางไว้ **ในโฟลเดอร์นี้โดยตรง** (ระดับเดียวกับไฟล์นี้ ไม่ใช่วางทั้งโฟลเดอร์ `tfjs_model`)
แล้วเว็บไซต์ (`index.html`) จะโหลดไปใช้งานได้ทันที

ถ้าเปลี่ยนโมเดลใหม่: ให้วางไฟล์ทับของเดิม ถ้าจำนวนไฟล์ `.bin` ไม่เท่าเดิม ให้ลบ `.bin` เก่าออกก่อน

ไฟล์ `README.md` นี้ไม่มีผลกับเว็บ ปล่อยไว้ได้
